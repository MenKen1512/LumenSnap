# LumenSnap — руководство

Предварительная версия 0.1.1 для Windows 11 x64. Работает локально, без аккаунта,
обновлений по сети и отправки изображений. Сборка без цифровой подписи.

Запустите установщик `LumenSnap-Setup-0.1.1-win-x64.exe`. Установка для текущего
пользователя, без обязательного автозапуска. Запустите LumenSnap из меню «Пуск».
Значок появится в трее. По умолчанию захват — **Ctrl+Alt+S**. Если сочетание
занято, используйте «Новый скриншот» в трее и выберите другое в «Настройках».
PrintScreen, Windows и Lightshot автоматически не перенастраиваются.

1. Выделите область мышью. За углы и стороны можно изменять размер.
2. Пробел + перетаскивание перемещает область, сохраняя объекты.
3. Выберите карандаш, стрелку, текст, линию, прямоугольник или эллипс справа.
4. Повторный щелчок по инструменту или нижняя цветная кнопка открывает параметры.
5. Щелчок по объекту выбирает его; перетаскивание перемещает, нижний правый
   маркер меняет размер. ПКМ также выбирает объект; Delete удаляет выбранный.
6. Двойной щелчок по тексту открывает ввод; доступны переносы строк, кириллица,
   шрифт, размер, полужирное начертание, выравнивание, фон и обводка.

**Ctrl+C** копирует изображение и закрывает захват только после успеха.
При фокусе в текстовом поле Ctrl+C копирует символы и сохраняет сеанс.
Первый Esc во время ввода фиксирует текст; следующий Esc закрывает захват.
Ctrl+Z / Ctrl+Y в текстовом поле управляют текстом; вне него — объектами.
**Ctrl+S** всегда открывает «Сохранить как»; отмена оставляет изображение и правки.
**Ctrl+P** открывает диалог печати. PNG сохраняет точные пиксели; JPEG использует
качество 95 и является форматом с потерями. BMP и PNG без потерь; фон непрозрачен.
Панели, затемнение, рамки и маркеры не включаются в результат.

Параметры: `%LOCALAPPDATA%\LumenSnap\settings.json`. При повреждении используются
безопасные значения по умолчанию. Выход — через меню трея. Повторный запуск
обращается к существующему экземпляру и открывает захват.

Обновление: завершите LumenSnap через трей и запустите новый Setup.exe.
Настройки сохраняются. Удаление — «Установленные приложения» Windows; личные
настройки можно сохранить или удалить в диалоге. Тихое удаление сохраняет их;
параметр `/PURGESETTINGS=1` явно удаляет настройки. Удаляется только автозапуск
LumenSnap. Для отката удалите новую версию, сохраните настройки и установите
нужную предыдущую сборку вручную.

Для большой области редактор автоматически уменьшает только вид рабочего стола,
оставляя панели снаружи; масштаб указан в подсказке. Экспорт остаётся в исходных
пикселях. На экранах, физически меньших размеров самих панелей, они скрываются;
доступны Ctrl+C, Ctrl+S, Ctrl+P и Esc.
Ограничения предварительной версии:
Точки карандаша отдельно не редактируются; объект перемещается и масштабируется.
Изменение размера текстового блока не меняет кегль; текст за его границей
обрезается при экспорте, размер блока нужно увеличить. Обводка видна после
завершения ввода. Производительские Fn-клавиши доступны только при наличии
клавиатурного события Windows. HDR, защищённое видео и эксклюзивный полноэкранный
захват не гарантируются. Матрица приёмки: `docs/VERIFICATION.md`.

### Изменения интерфейса 0.1.1

Панели уменьшены в 1,5 раза: толщина 34,67 DIP вместо 52. У кнопок появились
векторные значки и состояния наведения, нажатия и фокуса. У выделения — внешнее
голубое свечение; в сохранённый снимок оно не попадает. Настройки сгруппированы
по смыслу, у текста отдельно доступны типографика и оформление.

Справа от «Сохранить» находится **«Закрыть»**: отменяет текущий захват без
копирования и сохранения, LumenSnap продолжает работать в трее.
